# The Failure Club at Virginia Tech

Website for The Failure Club. *Failing Successfully.*

## Put it online with GitHub Pages

1. Create a new public repository on GitHub, for example `failureclub`.
2. Upload everything in this folder (`index.html`, `README.md` and the `assets` folder) to the repository.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, then pick the `main` branch and the `/ (root)` folder. Click **Save**.
5. After a minute or two the site will be live at `https://<your-username>.github.io/failureclub/`.

## Before you share it

- In `index.html`, find the **Join** section near the bottom and replace the two `href="#"` links with the club's real GobblerConnect page and Instagram URL.

## Files

- `index.html`: the whole site
- `assets/logo.png`: the logo with a transparent background
- `assets/favicon.png`: the browser tab icon
- `assets/team/`: the exec headshots
